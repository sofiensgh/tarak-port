# tarak-port

Portfolio of **Tarek Mazouzi**, Telecom Consultant (RAN & Radio), with a radio-network theme: a live background of cell towers and a drive-test UE whose RSRP / RSRQ / SINR readings drive the UI.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # static site in dist/
```

CV content lives in `src/data.js`. Put the CV PDF at `public/Tarek_Mazouzi_CV.pdf` for the download button.
